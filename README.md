# 🗿 Archaeologists of Mastodon ⚱️

A community-maintained list of archaeologists and archaeological institutions on [Mastodon](https://en.wikipedia.org/wiki/Mastodon_(software)) and the wider Fediverse. The web app lets you browse the list and bulk-follow accounts by downloading a CSV file to import directly into Mastodon.

**[→ Browse and follow the list](https://stark1tty.github.io/Mastodon-Archaeology/)**
Also available via [Find Sciences.Social](https://find.sciences.social/)

---

## Adding yourself to the list

Sign up via the **[Google Form](https://forms.gle/QdsUDAZfYZ6aTzYQ9)** (preferred), or DM [@NikaShilobod@fediscience.org](https://fediscience.org/@NikaShilobod) on Mastodon. Additions are usually processed within 24 hours.

Full names are only included if shown publicly in your profile or on explicit request. You can remove yourself at any time via the form or by opening a pull request.

## Development

Adapted from [Mastodon-Sociologists](https://github.com/trutzig89182/Mastodon-Sociologists) by David Adler, Thomas Haase, and Hendrik Erz.

The account list is stored in [`resources/users.csv`](resources/users.csv). To run locally, open `index.html` in a browser — no build step required.
